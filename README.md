# Essor - Revamped

Essor - Revamped is the successor of Essor, a Minecraft modifier initially made on Forge and Neo Forge. It aimed to redesign the progression system for armour, weapons and tools thanks to an action-based levelling system. This new revamped version aims to bring a new fresh start to Essor, with a huge change in its design philosophy, but also in its technical aspect.

## Design philosophy

Back then Essor was relying on an enchantment-based rewarding system aimed to be coupled to an item-based rewarding system in further updates. Over time, I came up with the conclusion that it was ruining Minecraft default's progression system by making the enchantment table completely unworthy. Moreover, when I started to conceive an item-based rewarding system, I came up with the conclusion that such a system would not only ruin farming and trading, but also the economy of a server.

For these reasons, the design philosophy behind this modifier evolved to reach its current state. Thanks to new experience tables, but also to new ways to display information, the levelling system is here for measuring the progress of the player in its usage of the tool.

The rewarding system is the biggest thing to deal with; It requires investigation about proper ways to reward an item. The enchantment-based and the item-based rewarding systems have been completely dropped. Instead, a durability bonus is now applied to each item depending on its level. It is a way to reward each item in a specific and useful way that does not ruin the enchantment table, nor any other aspects mentioned previously.

## Technical aspect

Essor - Revamped is developed with Love with the Fabric mod launcher. As these words are written, 17.09.2026, no version for alternative mod launcher is planned. Some features are missing in the v1.0.0 of the revamped mod, compared to its default equivalent's last update. These will come slowly. It has been done purposefully to redesign everything completely in a cleaner and more elegant way that fits the gameplay well.
